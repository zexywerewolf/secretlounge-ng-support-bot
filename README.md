# secretlounge-ng-support-bot

## Quick Start
- Add your bot to the group you want messages forwarded to.
- Create `config.yaml` from the template. Fill in the appropriate values (see `Getting Group ID` below).
- Run `pip install -r requirements.txt`
- Run `python3 supportbot.py`

## Getting Group ID
- Log in to [Telegram Web](https://web.telegram.org) in your browser.
- Open the specific group chat. Look at the URL in your browser address bar.
- Copy the numbers following the # symbol (it will look like #-123456789 or -100XXXXXXXXXX).
